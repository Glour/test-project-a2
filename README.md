# Flowly — мини‑CRM для работы с лидами

Готовое тестовое задание: автономная веб-страница без сборки и зависимостей. Откройте `index.html` в браузере — всё работает сразу.

## Что реализовано

- Добавление лида: имя, телефон, источник, ответственный, этап и признак «Запрошено ТЗ».
- Дружелюбная валидация: отдельно подсвечивает пустые поля и короткий номер телефона.
- Карточки лидов с полными данными, инициалами и понятными статусами.
- Воронка: счётчики лидов на каждом этапе.
- Поиск по имени или телефону и фильтр по этапу.
- Дополнительное задание: этап меняется в карточке и сохраняется сразу.
- Сохранение в `localStorage`: лиды и изменения остаются после обновления страницы.
- Удаление с подтверждением и ненавязчивые уведомления о действиях.
- Адаптивная вёрстка для телефона.

## Как показать работодателю за 2 минуты

1. Нажмите «Сохранить лида» с пустой формой — видно валидацию обязательных полей.
2. Добавьте клиента, выберите «Тёплый», «МОП», «Квалифицирован» и включите ТЗ.
3. Покажите карточку, счетчики воронки и поиск.
4. Смените этап прямо в карточке — он обновится и в воронке.
5. Обновите страницу: данные не исчезнут, потому что лежат в `localStorage`.

## Ориентация в коде

- [index.html](index.html) — интерфейс: форма, воронка, фильтры и список карточек.
- [styles.css](styles.css) — дизайн-система и адаптивная вёрстка.
- [app.js](app.js) — три явно отмеченных блока: `ХРАНЕНИЕ ДАННЫХ`, `ИНТЕРФЕЙС`, `ВАЛИДАЦИЯ И СОЗДАНИЕ ЛИДА`.
- Кнопка сохранения — обработчик `form.addEventListener('submit', ...)`.
- Постоянное хранение — `getLeads()` / `saveLeads()` в `app.js`.

## Роль нейросети и самостоятельная проверка

Нейросеть использовалась как ускоритель: помогла с начальной компоновкой, стилизацией и заготовками JavaScript. Самостоятельно проверены сценарии валидации, добавления, смены этапа, фильтрации, удаления и восстановления данных после перезагрузки. Итоговое решение намеренно не содержит библиотеки или сервер: для задачи на 20–25 минут это делает его прозрачным, быстрым для запуска и легко проверяемым.
