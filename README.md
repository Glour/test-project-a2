# Flowly — мини‑CRM для работы с лидами

Тестовое задание: одностраничное React‑приложение для создания и ведения лидов. Данные сохраняются в браузере, поэтому сервер, авторизация и база данных для запуска не нужны.

## Быстрый запуск

**Требование:** Node.js `20.19+` или `22.12+`.

```bash
git clone git@github.com:Glour/test-project-a2.git
cd test-project-a2
npm install
npm run dev
```

После запуска Vite выведет локальный адрес (обычно `http://localhost:5173`). Откройте его в браузере.

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

В репозитории есть `pnpm-lock.yaml`, поэтому вместо npm также можно использовать `pnpm install` и `pnpm run dev`.

## Что сделано

- Форма добавления лида с полями: имя клиента, телефон, источник, ответственный, этап сделки и «Запрошено ТЗ».
- Валидация обязательных полей: имя и телефон; для телефона дополнительно проверяется минимальная длина.
- Вывод каждого сохранённого лида отдельной карточкой со всеми введёнными данными.
- Сохранение лидов в `localStorage` — данные и изменения остаются после обновления страницы.
- Дополнительное задание: этап можно изменить прямо из карточки лида.
- Воронка с количеством лидов на каждом этапе, поиск, фильтр по этапу и удаление лида с подтверждением.
- Адаптивный интерфейс для десктопа и мобильного экрана.

## Сценарий проверки за 2 минуты

1. Откройте страницу и нажмите **«Сохранить»** с пустыми полями.
   - Появятся сообщения «Укажите имя клиента» и «Укажите номер телефона».
2. Заполните форму, например:
   - Имя: `Анна Петрова`;
   - Телефон: `+7 (999) 123-45-67`;
   - Источник: `Тёплый`;
   - Ответственный: `МОП`;
   - Этап: `Квалифицирован`;
   - включите «Запрошено ТЗ».
3. Нажмите **«Сохранить»**.
   - Новый лид появится в базе ниже; в карточке будут видны все выбранные значения.
4. Измените этап в карточке на «Назначена консультация».
   - Карточка и счётчик воронки обновятся сразу.
5. Обновите страницу браузера.
   - Лид и выбранный этап сохранятся.

## Структура проекта

```text
src/
├── App.jsx                  # Композиция экрана и состояние поиска/фильтра
├── main.jsx                 # Точка монтирования React
├── components/
│   ├── LeadForm.jsx         # Интерфейс формы, валидация и кнопка «Сохранить»
│   ├── LeadsList.jsx        # Карточки лидов, поиск, фильтр и смена этапа
│   ├── Pipeline.jsx         # Счётчики этапов воронки
│   ├── Header.jsx           # Шапка и сводка
│   ├── QuickStart.jsx       # Информационный блок
│   └── Toast.jsx            # Уведомления об успешных действиях
├── hooks/
│   └── useLeads.js          # Работа с localStorage: создание, изменение, удаление
├── constants/
│   └── leads.js             # Список этапов и начальное состояние формы
└── styles.css               # Стили и адаптивная вёрстка
```

## Где находится логика задания

| Что искать | Где находится |
| --- | --- |
| Интерфейс страницы | `src/App.jsx` и `src/components/*` |
| Кнопка «Сохранить» и проверка формы | `src/components/LeadForm.jsx`, `handleSubmit()` и `validate()` |
| Создание карточки | `src/components/LeadsList.jsx`, компонент `LeadCard` |
| Постоянное сохранение | `src/hooks/useLeads.js`, `useEffect()` с `localStorage` |
| Дополнительное задание — смена этапа | `src/components/LeadsList.jsx` и `updateLeadStage()` в `src/hooks/useLeads.js` |

## Использование нейросети и самостоятельная проверка

Нейросеть использовалась как инструмент ускорения: для начальной компоновки, стилизации и заготовок React‑компонентов. Самостоятельно выполнены проверка требований, запуск приложения, production‑сборка и тестирование сценариев: валидация, добавление лида, отображение данных карточки, изменение этапа, поиск, фильтрация, удаление и восстановление данных после перезагрузки.
